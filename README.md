# swarm-target

The codebase the swarm works on. Seeded backlog lives in GitHub issues; each issue has
acceptance criteria. Hidden regression tests used only for scoring live on a branch
agents cannot read.

Seeding (codebase + ~50 issues: ~35 independent, ~10 sharing a module, ~5 changing a
public interface) is the next step — see swarm-control/docs/implementation.md.
